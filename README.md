# Mini Komander Build — AI Blueprint QTO & RAB Engine

An automated **Quantity Take-Off (QTO)** and **RAB (Bill of Quantities / Tender Budget)** / **RAP (Execution Budget)** prototype built for construction drawings (`.dxf` & `.jpg`/`.png`), featuring local dataset calibration, *Human-in-the-Loop QS Review*, **Supabase PostgreSQL** persistence, and **Komander Core Cost Agent** alert simulation.

---

## Key Features

1. **Path A — AutoCAD Vector Engine (`ezdxf`)**
   - Extracts geometric entities from `.dxf` files (`LINE`, `LWPOLYLINE`, `CIRCLE`, `ARC`, `INSERT`, `HATCH`, `TEXT`, `MTEXT`) and reads `$INSUNITS` (with automatic mm/cm/meter inference from bounding-box spans).
   - Generates a programmatic 10m × 12m residential floor plan sample (`.dxf`) via `/api/sample-dxf`.
2. **Path B — Computer Vision Engine (`opencv-python-headless`)**
   - Detects structural wall segments using *Adaptive Canny Edge Detection* and *Probabilistic Hough Transform* (`HoughLinesP`) scaled to image diagonal.
   - Detects closed room contours (`findContours`) and highlights the *Title Block (Kop Gambar)*, returning a Base64 visual overlay.
3. **Dataset Calibration (`api/train_dataset.py` → `api/learned_model.json`)**
   - Learns geometric and visual priors from the local datasets:
     - `../examples_dxf/` (**47** `.dxf` files)
     - `../images/` (**453** `.jpg` floor plans, 120 scanned for statistical calibration)
   - Exposes `/api/dataset/summary` and `/api/dataset/analyze` to inspect and test dataset samples directly.
4. **Human-in-the-Loop QS Review & RAB/RAP**
   - Items with confidence scores below 85% are automatically flagged (`Cek QS`) and can be isolated with *Filter: Hanya Flag AI*.
   - Inline quantity edits automatically mark items as `Verified (99.9%)` and recalculate Total RAB, Total RAP, and Estimated Gross Margin in real time.
   - Supports saving projects and QTO items to **Supabase PostgreSQL** (with a local `FALLBACK_HSPK` fallback when `.env` is not configured) and simulates a **Komander Core Cost Agent** WhatsApp deviation alert.
5. **Tactile Neo-Editorial Scrollytelling UI/UX**
   - Built following the design system in `../uiux.md`: *Alabaster* (`#f8f9fb`) ↔ *Carbon Ink* (`#0b0b0c`) ↔ *Sage Plaza* (`#b9c4bd`) surface rhythm, `Inter` + `Instrument Serif` + `JetBrains Mono` typography, 3D keycap buttons (`.key-ink`, `.key-white`), `.zero-halo` prototype window, 3D flip cards, and a *Floating Bottom Glass Dock*.

## Running Locally

### 1. Backend Setup (Python FastAPI)

```powershell
cd mini-komander-build
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

*(Optional)* Re-run dataset calibration if you add new files to `../examples_dxf` or `../images`:

```powershell
python api/train_dataset.py
```

Start the FastAPI server on port `8000`:

```powershell
uvicorn api.index:app --reload --port 8000
```

### 2. Frontend Setup (React + Vite)

In a separate terminal:

```powershell
cd mini-komander-build
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/health` | API health status and dataset calibration timestamp |
| `GET` | `/api/sample-dxf` | Download sample AutoCAD `A-101_Denah_Blok_M1.dxf` |
| `POST` | `/api/analyze-cad` | Extract QTO items from an uploaded `.dxf` file |
| `POST` | `/api/analyze-vision` | Detect lines, room contours, & OpenCV overlay from `.png`/`.jpg` |
| `GET` | `/api/dataset/summary` | Summary statistics for `examples_dxf` & `images` |
| `POST` | `/api/dataset/analyze` | Analyze a specific sample directly from the local dataset |

npx vercel --prod

Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in **Project Settings → Environment Variables** on the Vercel dashboard before redeploying.
